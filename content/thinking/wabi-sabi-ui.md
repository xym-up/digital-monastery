# UI 设计中的侘寂

> 侘寂（Wabi-Sabi）：在不完美中发现美，在无常中看到价值。

## 当设计遇到禅

现代 UI 设计追求的是什么？像素级精确、一致性、可预测性。但日本美学中的 **侘寂** 告诉我们另一种可能。

侘寂接受三件事：
1. **Nothing lasts** — 没有什么是永恒的
2. **Nothing is finished** — 没有什么是完成的
3. **Nothing is perfect** — 没有什么是完美的

## DOM 的无常

想想一个 React 组件的生命周期：`mount → update → unmount`。每一个 DOM 节点都是无常的。它会被创建，被修改，最终被销毁。

这不是 bug，这是宇宙的运行方式。

## 留白即是丰富

在侘寂美学中，**空** 不是缺失，是充满可能性的空间。

当你在页面上留出大量空白时，你不是在浪费像素——你是在给思想留出呼吸的空间。这正是 Digital Monastery 的设计理念：少即是多，空即是满。

好的设计不是添加到无法再添加，而是删减到无法再删减。
