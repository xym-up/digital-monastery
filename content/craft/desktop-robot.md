# 从零手搓桌面机器人 — 一个极客的造物日记

> 「最好的学习方式是造东西。」

## 动机

我一直想做一个实体的东西。写代码写久了，总觉得少了点什么——屏幕里的像素很美，但它们没有重量、没有温度、不会在你桌上晃来晃去。

桌面机器人是一个完美的入门项目：足够小，不需要太多空间和预算；足够复杂，涉及硬件、软件、结构设计多个维度；足够有趣，做完了可以放在桌上当伴侣。

## 硬件选型

经过一番调研，我选定了以下配置：

**主控**：ESP32-S3。便宜（不到 30 块）、支持 Wi-Fi 和蓝牙、有足够的 GPIO、社区资源丰富。而且它支持 MicroPython，对我这个主要写 Python/JS 的人很友好。

**驱动**：两个 SG90 舵机，控制头部的左右旋转和上下俯仰。SG90 便宜、体积小、扭矩对于桌面机器人来说足够。

**显示**：一块 0.96 寸 OLED 屏幕作为「脸」，用来显示表情。128x64 的分辨率画简笔画表情绰绰有余。

**外壳**：3D 打印。学校创客空间有打印机，我用 Fusion 360 建模。设计理念是圆润、可爱、容易组装。

## 当前进度

这是一个种子阶段的项目，目前只完成了最基础的部分：

- [x] ESP32 开发环境搭建（Arduino IDE + ESP32 Board Package）
- [x] 舵机控制测试（PWM 信号驱动 SG90）
- [x] OLED 屏幕驱动（I2C 协议，SSD1306 驱动芯片）
- [ ] 3D 模型设计（进行中）
- [ ] 表情系统（预设几组眼睛动画）
- [ ] 语音交互（接入 AI 语音 API）
- [ ] 环境感知（温度 + 距离传感器）

## 一些坑

**电源问题**：两个舵机同时运动时电流可能超过 USB 供电能力，导致 ESP32 重启。解决方案是舵机用独立电源供电。

**舵机抖动**：SG90 在保持位置时会轻微抖动，这是这个价位舵机的通病。可以在不需要保持位置时断开 PWM 信号。

**3D 打印公差**：我的模型第一版设计了太紧的配合公差，打印出来根本装不进去。后来学会了在配合面预留 0.3mm 间隙。

## 为什么要做实体项目

最大的感触是：和物理世界打交道的反馈完全不同于写代码。代码里的 bug 是逻辑错误，改代码就能修。硬件的 bug 可能是焊点虚焊、线松了、舵机坏了——你需要用万用表量、用示波器看、用手去摸。

这种多感官的调试体验让大脑的不同区域都活跃起来了。我觉得每个程序员都应该试试做点硬件，哪怕只是点亮一个 LED，那种「我写的代码让物理世界发生了变化」的感觉，比任何 UI 动画都震撼。
